# PUUZ SECURITY 1.3.1 — Nâng cấp giao diện

Bản 1.3.1 tập trung vào trải nghiệm giao diện: bố cục thích ứng theo kích thước cửa sổ, màu menu có thể tùy chỉnh, chuyển sắc dịu mắt, khoảng cách/card/button nhất quán và animation mượt. Các tính năng hiện có như Money History, Quick Pay, Map Shield, Password Shield, Tooltip Protection và Update Checker được giữ nguyên.
