# PUUZ SECURITY 1.2.5 — Quick Pay

## Behaviour
- `Quick Pay` is a client-only keybind and defaults to `NONE`.
- The user may assign any key in Minecraft Controls.
- The action requires holding `Shift` while pressing the configured key.
- The crosshair must be on another player.
- PUUZ SECURITY opens the normal Minecraft chat with `/pay <player> ` prefilled.
- The amount is intentionally left blank so the user enters it manually.
- PUUZ SECURITY never invents an amount and never sends a payment without the user's confirmation.
- No network request is generated by the mod.
- The optional `Quick Pay Amount` keybind also defaults to `NONE` and is reserved for the optional amount-entry workflow; it does not alter the default quick-pay behaviour.

## Compatibility
The implementation uses Fabric's client keybinding system and the 1.21.x `ChatScreen(String, boolean)` constructor. Fabric key mappings are client-side and are exposed through Options > Controls. See the official Fabric key mapping documentation.
